# 一、项目概要与预审意见

公司拟利用二号厂房现有空间建设两条电池托盘焊接与检测线，承接T-240型号客户平台导入需求。该项目主要完成来料检验、定位焊接、精加工、气密检测和出厂质量追溯，不包括铝型材挤压、压铸、电池电芯制造及电池包装配。

按正常运营年客户预测需求24.00万套、合格产能25.4016万套测算，产能可覆盖基准需求，但不宜将剩余能力全部承诺给新增客户。融资前项目资金需求为8,858.23万元，距9,000.00万元控制上限仅有141.77万元余量，设备询价和账期变化均可能改变预审结果。

## 3.1 拟采用工艺与验收边界

供应商方案[资料02、资料03]提出，每条线在约定产品与连续作业条件下设计毛产出速率为30套/小时。精加工、气密和终检单元按两线30套/小时的配套边界配置；该边界内暂不作为额外瓶颈，不再重复折减产能。超过该速率、增加线体或更换产品后，必须重新进行瓶颈校核。

关键验收条件包括约定型号的连续节拍验证、最终合格率验证以及单套质量记录可追溯。节拍和合格率目前均为规划取值，不是量产实测成绩；采购技术协议应补充样件状态、持续运行时长和统计方式，不能只凭短时演示确认达产。

# 四、产能测算与交付匹配

表4-1 产能测算输入

| 参数 | 采用值 | 定义 |
| --- | --- | --- |
| 并行生产线数量 | 2条 | 仅本项目新增线 |
| 每年工作日 | 300天 | 规划输入，不由日历自动生成 |
| 每日班次 / 每班时长 | 2班 / 8小时 | 每条线一致 |
| 单线毛产出速率 | 30套/小时 | 尚未扣除质量损失 |
| 有效开动率 | 90% | 计划换型、维护和停机的时间折减 |
| 最终合格率 | 98% | 与时间折减独立，含允许返修后的结果 |
| 正常年需求 | 240,000套 | 来自表2-1 |
| 首年需求 | 180,000套 | 来自表2-1 |

按[资料02]规定，先计算两线计划线时，再扣除非有效作业时间，最后扣除不合格品。有效开动率不是包含质量损失的综合效率指标，不能与最终合格率重复扣减。年合格产能不足整数套时向下取整。

合格年产能 = 向下取整（线数 × 年工作日 × 日班次 × 每班小时 × 单线毛产出速率 × 有效开动率 × 最终合格率）

= 向下取整（2 × 300 × 2 × 8 × 30 × 90% × 98%）= 254,016套

两线计划线时为9,600线小时，经90%的时间折减后，年毛产出为259,200套，最终合格产能为254,016套，即25.4016万套。正常年计划销售240,000套，能力余量14,016套，计划产能占用率为94.48%（销量÷合格产能）。

首年客户需求180,000套低于同一规划能力，因此首年计划销售仍为180,000套。该年爬坡反映在客户导入量中，本次不再叠乘一个未定义的“爬坡率”。若首年设备可用时长另有变化，应单列期间参数重算，而非保留旧销量。

## 4.1 交付结论与复议条件

在现有参数下，基准需求可以覆盖；这一判断依赖30套/小时、90%和98%三个条件共同成立。当计算能力低于客户需求时，销售上限随能力下降，需求缺口单独列示，不能把未生产的部分继续计入收入。能力余量也不直接证明加急插单可行，周度峰值、换型顺序和物流窗口尚未建模。

本轮未设置“产能占用率不超过某百分比”的额外淘汰门槛。94.48%的占用率只能说明平均能力使用程度，不能自行推导为“交付风险低”。当速率、工作日、开动率或合格率变更时，表1-1、表3-1、销量、经营测算与相关结论均应重新核对。

## 5.2 配电资料分歧与用能预算

[资料06A]和[资料06B]均以2026年9月1日为统计基准，描述二号厂房接入点扣除已投运及已批准项目后的可用有功余量，但分别给出800kW和650kW。后者形成时间较晚，尚不能解释差异，也未明确废止前一记录；本报告不自行选择其中较大或较新的值。

设备方案新增最大有功需量为720kW。采用800kW时余量为80kW；采用650kW时缺口为70kW。两种结果对应不同的适配判断，故当前结论为“待联合复测”，不得替换成确定满足或确定不满足。公辅改造280.00万元暂不含变压器增容及外线接入工程，是否追加投资尚无法定量。

正常年生产用电按8千瓦时/合格销售套估算，已经折入本方案平均损耗，不再除以合格率。正常年用电量为192.00万千瓦时，未超过公司为本项目暂定的200.00万千瓦时年度内部预算。该预算不是行政核定指标；年电量低于预算也不能证明720kW瞬时负荷可以接入。

## 10.2 简化静态资金回收

建设期按1年计。全部建设投资和正常年净营运资金在投产前投入，首个运营年度取得2,355.60万元经营现金盈余，之后各年暂按正常年3,688.80万元延续，不计残值及营运资金回收。各运营年度内现金盈余按均匀取得作线性插值。该口径用于同类方案初筛，不替代折现评价。

回收期 = 建设期年数 + 1 +（融资前资金需求－首年经营现金盈余）÷ 正常年经营现金盈余

= 1 + 1 +（8,858.232－2,355.60）÷ 3,688.80 = 3.76年

上述简式只适用于首年结束尚未收回初始资金且正常年盈余大于零的情形；若前提改变，应按累计收支重新定位回收年度，不套用旧式。基准3.76年未超过公司本轮4.00年初筛线，但该结果依赖未锁定的售价、材料价格、需求与账期，不能据此保证实际回收年限。

建设期利息、税款收付和长期更新安排不完整，本报告不列内部收益率、净现值、税后回收期及偿债覆盖指标，也不以经营现金盈余直接证明能够按约还本付息。
