## 建议的分层验收

1. **文档层**：原件摘要、页数、目录与页码，正文及表格的块级位置可回链；扫描件应提示 OCR，不能产出空白成功结果。
2. **通用语义层**：人工标注一小组事实、单位、时点、来源、论断及证据位置，检查召回、误抽和不可判定情况。数值 `0`、空值和缺资料须区分。
3. **领域层**：北京可研稿用于检验建设项目领域包的迁移，但不能直接复用澄岳精密的行业事实与计算规则。环评、审计、事故调查先做通用抽取测试；各自有章节、事实、证据和审查规则后，才做受控写作测试。
4. **写作层**：对每个已配置领域，准备一份**新的项目输入**和人工审定的目标报告；测试“抽取→人工校对→项目事实→规则/证据→章节起草→审查→导出”全链路。历史报告只能提供结构和经过审核的可复用语料，不得把历史项目数值带入新项目。

建议把北京可研稿作为首个异项目留出样本；另外三份是跨类型边界样本。单有这些历史报告，还不能验证新项目写作质量：仍需新的项目输入、领域规则和人工审定答案。
