# NEXT-02A 类型化信息替换实验预注册

对象是澄岳精密 `cy_tray_20260918@v2` 的合成 QA 写作试验，只覆盖 S4、S7.1、S5.2。类型化契约固定在 `backend/app/writing_contract.py` 的 `QA_CONTRACTS`，实验运行时不修改它。它转录同一份虚构历史资料的**信息内容**，并接收当前项目的事实与规则；这不是新的独立业务报告，也不是新证据。

## 固定输入与可证伪条件

| 章节 | 项目或历史输入 | 应保留的输出边界 |
| --- | --- | --- |
| S4 | 新项目需求 300,000 套、合格能力 254,016 套，项目 `min` 规则得 254,016 套 | 需求不写成订单；历史 EV-01 只有摘录；旧条件句按项目事实排除 |
| S7.1 | 新供应商“新拓设备”、单价 1,234.50 万元/条 | 不继承禾进装备、历史报价范围或采购判断 |
| S5.2 | 历史同口径余量 800 kW 与 650 kW，EV-06A/B 只有摘录，冲突未解决 | 仅披露历史分歧，不作新项目配电适配结论 |

对每类先运行已入库记录的正常候选，再用类型化契约中的结构、槽位、项目规则、受限论断或双来源冲突重新生成。比较正文、项目事实值和保留事项；另核对类型化字段与原数据库记录的可观察信息相符。**更改 record_id 而保留旧生成逻辑不算替换。**类型化生成器不得读取 `CorpusRecord`，原记录 ID 只作为实验来源映射，不写入替代候选或报告。

类型化契约只覆盖这三个章节实际消费的字段；未替代整个类别的所有记录、元数据或审计职责。

| --- | --- | --- |
| 04 | 章节 ID、标题、层级 | 章节 ID 改错，阻断 |
| 09 | 页码与正文区间 | 区间为空，阻断 |
| 10 | 类型、单位、数值格式和槽位 | 单位改为“台”，阻断 |
| 13 | 本项目 min 规则及依赖 | min 改为 max，阻断 |

每个类别只在其已验证使用的章节试验：S4 为 04/09/10/13/15/18/27；S7.1 为 04/09/10/27；S5.2 为 04/18/23/27。其余章类组合返回 `not_supported`，不能把未消费类别记作“等价”。15 个适配组合分批运行，每次最多选择 6 类。

## 接口和判定

`POST /api/projects/{project_id}/writing/materials/{section_id}/simulate` 可加 `experiment_mode: "equivalent"`；默认 `"remove"` 保留原逐类移除实验。等价实验逐项返回 `status`、替代前后文字、历史 `used_records` 映射、`contract` 和 `checks`。`contract.fields` 是真正被类型化生成器消费的字段；`validation.negative_result` 应为 `blocked` 或 `changed`。`checks` 必须同时满足正文、项目值、边界、原记录信息和负例检验，才标记 `equivalent`。

失败条件：缺字段或错误字段仍生成同一合格候选；未保留 0/缺值/min 结果；历史供应商、报价范围或无条件配电结论进入文本；将摘录提升为完整证据；把历史记录 ID 写成新项目来源；模拟改动项目事实、配置或报告版本。0、缺值和条件变化另由前述 NEXT-02 测试覆盖。

`equivalent` 只说明**该实验中同等信息可以由类型化结构承载**，不证明该类信息对所有报告必要，也不证明新项目可摆脱原件、来源位置或人工复核。尤其 09 的替代仍转录了历史位置；若没有可核对原件，不能声称来源责任已经满足。18 和 23 只保留历史风险边界，不提供新项目证据。任何替代候选都只在内存中展示，不允许以模拟引用确认到正式报告。

## 本轮实际结果

主任务在独立 `report_platform_test` 集中运行 `test_writing_contract.py` 原有 5 项，均通过；其中 15/15 个真实数据库类别×章节 API 对比返回 `equivalent`，模拟前后项目事实及版本不变。另以不连接数据库的纯函数校核确认：15/15 个类别专属负变异均阻断，15/15 份类型化字段与冻结语料中对应字段一致。新增的低 Decimal 精度报价纯函数校核通过；其 pytest 用例等待下一轮集中测试。

这 15 个结果共享同一套**全章类型化 QA 重建**，每项通过该类别的负变异证明字段确实被消费。它们**不是** 15 条彼此独立的生产单类替换路径，也不是 15 份新业务原件。真实独立原件、跨报告类型和人工金标比对仍未验证。
