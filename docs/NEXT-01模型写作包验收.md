# NEXT-01 模型写作包验收

状态：限定场景已完成实现与验收。下列输入、预期和失败条件在实现与运行测试前固定，运行结果补记在文末。

## 验证范围

只验证已选只读澄岳语料版本下 S4 和 S7.1 的模型待审候选。新项目初始事实为空，历史事实值、正文、供应商、报价、条件句和审核结论均不能进入模型输入。模型输出不能直接成为已核对或可交付正文。

接口契约：`POST /projects/{pid}/reports/{rid}/writing/model-input` 接收章节、经用户批准的 `item_id` 与 `mode=model`，返回 `writing-input/v1`、稳定输入 SHA256 和逐项排除原因；`writing/preview` 的模型模式必须带 `expected_input_sha256`。取消不写报告；确认依赖签名，并将实际模型输入、调用、使用项与结果存入可查询和可导出的审计记录。

## 固定输入

| 代号 | 项目输入 | 章节与选择 | 模型输出条件 |
| --- | --- | --- | --- |
| S4-基准 | 首年客户需求 300,000 套；合格能力 254,016 套；项目规则 `min(first_year_demand, qualified_capacity)` 得计划销售量 254,016 套 | S4 必需的目录、模板、C0052 骨架、R006、L002；不勾选 CAT-26 风格 | 数值段分别写出三个项目值，引用实际发送的 C0052 骨架和 R006；另有逐字受限提醒段，仅引用 L002 |
| S4-零值 | 首年需求 0 套；合格能力 254,016 套；计算结果 0 套 | 同上 | 0 保持有效，不转成缺失或 254,016 |
| S4-缺值 | 首年需求未定义；合格能力 254,016 套 | 同上 | 不调用模型形成确定数值候选 |
| S7.1-身份 | 供应商“新拓设备”；单价 1,234.50 万元/条 | S7.1 必需结构与 C0083 骨架 | 可写项目事实，不能出现历史供应商“禾进装备”、历史报价范围或历史采购判断 |

S4 的 L002 提醒只接受这两句之一：`客户预测不能改写为已签订单或最低采购承诺。`；`上述需求仅作为本项目测算输入，不能据此认定已有已签订单或最低采购承诺。`。该段可以没有 `fact_keys`，但 `source_item_ids` 必须只含实际发送的 L002，或附带已发送的安全风格项。数值段必须独立定位三个事实值，不能以一个相同数值代替能力和计划销售量两个引用。

## 固定检查项

| 编号 | 操作 | 应观察到 | 判失败条件 |
| --- | --- | --- | --- |
| M01 | 取 S4 模型输入并捕获真正传给 `chat_json('writing', …)` 的用户 JSON | `project_id`、项目与报告版本、章节、语料版本、事实修订、证据状态、当前 min 规则和每个发送材料的稳定 ID 一致；SHA256 与预览使用的输入一致 | 端点响应与实际发送不一致；发送未经批准材料或另一个项目事实 |
| M02 | 不选 CAT-26 风格后生成；再显式选中风格重取输入 | 首次无风格材料；第二次仅有 tone/person 与安全数字格式 | 术语表、历史判断、历史金额或历史供应商进入风格内容 |
| M03 | 检查 S4 模型请求和生成结果 | 只发送受限结构、规则、论断提醒与当前项目事实；数值段引用已发送骨架和规则，提醒段引用 L002 | 任一历史原文正文、摘录、证据全文、旧供应商、旧金额、`需求低于能力` 条件句进入请求或候选；服务器自动替模型补充未引用来源 |
| M04 | 以 0 与缺值分别生成 | 0 算得 0 且可定位；缺值被拒绝且没有模型调用 | 缺值补零，或 0 被当缺值 |
| M05 | 仅预览后取消 | 报告版本、正文和模型确认审计条数不变 | 预览写入报告或标为已核对 |
| M06 | 确认有效候选后读取报告、模型审计和预审导出 `audit.json` | 报告增一版；每段回链项目事实和实际使用的语料材料；审计含输入哈希、模型调用、使用项、确认版号 | 审计缺任一链路，或将未发送来源贴到正文 |
| M07 | 取输入哈希后改事实，再用旧哈希预览；另改写确认包正文、使用项或模型输入 | 均拒绝，报告版本和模型审计不变 | 过时输入或篡改包被确认 |
| M08 | 模拟模型不可用、返回非法结构、空 `source_item_ids`、未知 `source_item_ids`、缺少 L002 提醒 | 明确错误，不产生候选确认事件 | 静默退回规则拼接文本或引用未发送材料 |
| M09 | 模型返回无来源确定数字、历史供应商、已签订单断言或失效条件句 | 拒绝，报告和审计不变 | 错误段落出现在候选或导出 |
| M10 | S7.1 使用新项目供应商和单价 | 只引用 C0083 已发送骨架与对应项目事实 | 出现“禾进装备”或历史报价范围 |

`review_only` 的原文切块、历史证据和摘录只供页面核对，不在模型材料内。用户批准但当前模式不支持的骨架进入 `excluded_items` 并给出原因。模型使用项只能来自实际发送的材料；`model_usage` 只记录模型实际报告的来源，不把写作包中所有类别自动算作模型贡献。

## 运行边界

自动化测试只可连接 `report_platform_test`，建表前断言数据库名；不清空或修改用户项目。真实模型密钥不进入测试、仓库、提示词或导出。模拟模型测试证明输入边界和保存机制；真实模型生成的自然语言质量仍需单独人工核对。澄岳是单一虚构语料，本项通过不等于跨报告类型能力通过。

## 验收结果

自动化模型边界用例在本轮后端全量回归中通过，覆盖 M01–M10；另有真实 DeepSeek 两章、共 4 次请求，走通预览取消、重新生成、确认、预审导出。S4 实际发送 5 条材料、S7.1 发送 3 条材料；报告最终 v2，确认审计 2 条，DOCX/PDF/审计内容核对一致。

真实模型未选用风格条目；其安全投影仅由自动化测试验证，不宣称风格有实证增益。模型候选仍需人工核对，项目未提供新原件，正式交付保持阻断。本轮真实模型没有重新测试零值场景，零值与缺值分别由自动化及确定性真实接口/浏览器测试覆盖。
