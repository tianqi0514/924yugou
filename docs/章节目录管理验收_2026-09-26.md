# 章节目录管理验收（2026-09-26）

## 实施前固定案例

| 案例 | 输入 | 预期与失败条件 |
|---|---|---|
| 空报告新增章节 | 新报告仅有标题和空段落，新增“项目背景” | 产生唯一章节 ID、标题块 ID 和空白正文；项目事实与推演不被创建；刷新后仍在目录 |
| 已有章节重命名、排序 | 澄岳 S4、S7.1 各带本次运行、来源和稳定块 ID；将 S7.1 上移，再改标题 | 全章正文/表格按顺序移动，块 ID、`section_id`、推演及来源引用逐项不变；旧版本可查看，DOCX/PDF 顺序一致；再次生成章节不覆盖人工标题 |
| 冲突与错误 | 旧 `base_version`、其他项目报告 ID、空标题、首章继续上移 | 旧版本和越权返回错误；非法标题与越界移动不产生新版本；任何失败不产生半移动 |
| 浏览器操作 | 在真实 Plate 工作台新增、命名、调整顺序，再保存/刷新、比较和导出；500px 宽度复核 | 目录按钮可操作，无整页横向溢出；选中章定位正文，普通人工内容保留；没有写作配置的自写章节不误用其他章的生成配置 |

## 实际结果

| 案例 | 验证结果 |
|---|---|
| 空报告新增 | 后端新项目测试通过：仅新建 `manual-*` 章节和空白正文，项目事实仍为空；重复标题拒绝且版本不变。浏览器先取消、再新增，取消不入库。 |
| 已有章节重命名、排序 | S4 与 S7.1 的标题、正文、表格按章移动；逐块比较原 ID、`section_id`、推演/来源引用不变。人工重命名标题在再次生成 S7.1 后仍保留。旧版比较可读取原正文。DOCX 和解析后的 PDF 均按新顺序出现三章，ZIP 审计仍绑定所选运行。 |
| 冲突与错误 | 旧版本返回 409；错误项目报告返回 404；空标题、边界移动返回 400。失败后的报告版本保持不变。 |
| 浏览器操作 | 真实前后端按“新增取消→新增确认→无配置章生成禁用→重命名→上移→刷新→版本比较”完成，数据库原引用块逐项相等；500px 窗口章节栏和正文可见，页面无整体横向溢出。 |

完整回归：后端 `133 passed`；真实前后端 Playwright `6 passed`；受控前端 `13 passed`；TypeScript 与 Vite 构建通过。测试写入仅限独立 `report_platform_test` 数据库；日常项目没有用于破坏性验收。首次全套运行中，一个旧浏览器测试的模糊“章节”选择器与新增的重命名按钮冲突，另一个测试在语料异步加载结束前读页面；已改为明确控件定位与等待后全套复测通过。并行运行时一次窄屏脚本达到原 30 秒超时，单独复测通过，将该多次刷新用例超时调整为 60 秒后前端全套通过。

## 当前边界

本轮提供新增、重命名和上移/下移，不实现拖拽排序、自动编号或跨报告复制。调整章节不推断自由文字的业务语义；从模型或规则生成候选仍需该章有适用的写作配置。
