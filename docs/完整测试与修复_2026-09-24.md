## 2. 已发现并修复

| 问题 | 修复 | 对应验证 |
|---|---|---|
| `min(10元,2万元)`曾返回2元，单位标签在逐参数比较中丢失 | min/max连续传播单位标签，乘除保留并组合原始单位；不同币值单位明确拒绝 | 直接表达式、0守卫、API拒绝及事务无变更 |
| Decimal精度只设置在导入线程，工作线程的计算与显示可能不同 | 每次计算/显示使用局部context；加减乘超出50位有效精度明确拒绝，精度检查不做有损舍入 | 线程精度9下仍按50位计算，长数字显示不丢失，不修改调用方context |
| 极大数值指数可能溢出或在格式化中分配巨大文本 | 输入、规则常量及结果限制指数，溢出/下溢返回明确业务错误 | 极大/极小指数被拒绝，事实、修订、规则均无半提交 |
| 删除最后一处事实引用后仍残留报告绑定快照 | 保存时按实际仍引用的事实裁剪绑定，项目事实不删除 | 保存回归中核对绑定为空、事实值保留 |
| 全空白项目名、事实名、报告名可通过长度验证 | 先去首尾空白再做非空验证 | API返回422，无新增记录 |
| 切章或保存材料配置后，晚到请求可能回填旧章节候选 | 请求代次与取消控制，配置变化使候选失效 | 延迟响应浏览器回归 |
| 事实改值后只能追加新章节，旧规则引用留在报告中持续阻断 | 预览旧段落后“替换本章”，同章原位置替换，其他内容和旧版本保留 | 签名、取消、版本、旧块审计及真实编辑流程 |
| 替换章节时重新绑定了同一事实的全部引用，其他段落的旧数值被误认作已核对 | 只在旧引用全部被替换或原绑定已是当前修订时刷新事实快照；影响列表定位实际含旧值的段落 | 替换回归保留人工旧引用，真实浏览器阻断到更新并重核对 |
| Plate 插入事实 token 时拆分段落，前半段可能留下没有数值的空事实绑定 | 按插入前的绑定保留情况清理临时绑定；编辑状态只剔除本次新加且无数字、无 token 的数值事实键 | 真实浏览器保存刷新后逐段检查绑定，再完成正式导出 |
| L002来源详情遗漏论断正文 | 来源预览支持pattern字段 | 真实来源抽屉显示“客户预测不能改写为已签订单或最低采购承诺。” |
| 折叠起草卡仍占300px空白 | 明确局部CSS优先级，折叠卡按内容收缩 | 浏览器高度与窄屏检查 |
